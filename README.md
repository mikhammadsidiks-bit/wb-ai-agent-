# WB AutoReply

Автоответчик на отзывы Wildberries. Использует две заданные фразы без изменений:

- 1–3 звезды: ответ на негативный отзыв.
- 4–5 звёзд: ответ на положительный отзыв.

## Подключение

1. Открой Settings → Secrets and variables → Actions в этом репозитории.
2. Создай Repository secret с именем `WB_API_TOKEN`.
3. Вставь туда действующий API-токен Wildberries с доступом «Вопросы и отзывы» → чтение и запись.
4. Открой Actions → WB AutoReply и нажми Run workflow для первого ручного запуска.

Никогда не добавляй токен в файлы, Issues, Discussions или сообщения. Если токен уже был опубликован или отправлен в чат, отзови его в кабинете WB и создай новый.

## Как работает

- GitHub Actions запускает проверку по расписанию примерно раз в 5 минут. GitHub может задерживать запланированные запуски; точное время не гарантируется.
- За один запуск обрабатываются до 500 неотвеченных отзывов за последние 24 часа.
- Оценки 1–3 получают негативную фразу, 4–5 — положительную.
- После успешной отправки отзыв исчезает из списка неотвеченных, поэтому повторный ответ обычно не отправляется.
- При временной ошибке или ограничении частоты запросов выполняются повторные попытки.

## Важно

Первый запуск может ответить на все неотвеченные отзывы за последние 24 часа. Проверь их список в WB перед первым запуском. Сейчас окно проверки установлено на 1 день.

Автоматические ответы публикуются от имени магазина. Проверь тексты и их соответствие правилам Wildberries перед включением.
