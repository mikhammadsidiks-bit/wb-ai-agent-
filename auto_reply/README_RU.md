# WB AutoReply

Автоответчик использует две фиксированные фразы:
- 1–3 звезды — ответ на негативный отзыв.
- 4–5 звёзд — ответ на положительный отзыв.

Проверка запускается GitHub Actions по расписанию примерно раз в 30 минут; задержки расписания возможны.

## Подключение

1. В настройках репозитория откройте Settings → Secrets and variables → Actions.
2. В Secrets создайте `WB_API_TOKEN` и вставьте персональный WB API-токен с правами чтения и записи в категории «Вопросы и отзывы». Токен не добавляйте в файлы или сообщения.
3. В Variables создайте `START_DATE` со значением даты запуска в формате `YYYY-MM-DD` (например, `2026-11-22`). Это не даст боту отвечать на более старые отзывы.
4. Откройте Actions → WB AutoReply → Run workflow для ручного первого запуска.
5. Посмотрите журнал запуска. Успешная отправка ответа WB возвращает HTTP 204.

## Важно

- Репозиторий содержит только код; секрет хранится отдельно в GitHub Secrets.
- Не отправляйте API-токен в чат и не публикуйте его.
- Перед включением расписания убедитесь, что дата START_DATE выбрана правильно: бот ответит на все неотвеченные отзывы начиная с этой даты.
- Бот отвечает только на отзывы, не на вопросы покупателей.
- Один запуск обрабатывает максимум 500 отзывов.
