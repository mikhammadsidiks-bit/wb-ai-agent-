# WB AutoReply

Автоответчик на отзывы Wildberries для нескольких магазинов в одном GitHub Actions workflow.

Использует две заданные фразы без изменений:
- 1–3 звезды: ответ на негативный отзыв.
- 4–5 звёзд: ответ на положительный отзыв.

## Подключение магазинов

В репозитории открой Settings → Secrets and variables → Actions → New repository secret.

Для первого магазина:
- Name: `WB_API_TOKEN`
- Secret: API-токен первого кабинета Wildberries.

Для второго магазина:
- Name: `WB_API_TOKEN_2`
- Secret: API-токен второго кабинета Wildberries.

Токены должны иметь доступ «Вопросы и отзывы» с правами чтения и записи. Не вставляй токены в исходники, Issues, Discussions или сообщения. Если токен уже был опубликован или отправлен в чат, отзови его в кабинете WB и создай новый.

Чтобы добавить третий и следующие магазины, добавь секреты `WB_API_TOKEN_3`, `WB_API_TOKEN_4` и так далее. Для них код автоматически создаст отдельную обработку. Необязательные названия магазинов задаются переменными окружения `WB_STORE_NAME_2`, `WB_STORE_NAME_3` и т. д.; сейчас второй магазин подписан «Магазин 2».

## Как работает

- GitHub Actions запускает проверку примерно раз в 5 минут. GitHub может задерживать запланированные запуски; точное время не гарантируется.
- Каждый магазин обрабатывается отдельно, со своим токеном.
- За один запуск для каждого магазина обрабатывается до 500 неотвеченных отзывов за последние 100 дней.
- Оценки 1–3 получают негативную фразу, 4–5 — положительную.
- После успешной отправки отзыв исчезает из списка неотвеченных, поэтому повторный ответ обычно не отправляется.
- Если обработка одного магазина завершится ошибкой, бот продолжит попытку обработать остальные магазины, а запуск будет отмечен ошибкой для проверки.

Автоматические ответы публикуются от имени соответствующего магазина. Проверь тексты и их соответствие правилам Wildberries.
